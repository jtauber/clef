# BE passives

Passive predications formed with BE and a past participle, where the subject corresponds to an object of the corresponding active verb.

## Conventions

- Include finite and non-finite BE, contractions, perfect passives and progressive passives.
- Include passives with or without an expressed agent.
- Count each coordinated passive predicate separately, even when BE is shared: *were selected and extracted* contains two occurrences.
- Exclude GET passives, HAVE/GET causatives and adjectival or ordinary copular uses of BE. Mark unresolved verbal/adjectival readings as unresolved.
- Mark BE and the passive participle. Intervening subjects, adverbs and complements stay outside the marked pieces; earlier perfect HAVE is not part of this feature's marking.
- With a shared auxiliary, mark it with the first coordinated participle and mark each subsequent passive participle as a separate occurrence.

## Notes

The contextual rule draws on MFTE's passive correction [@mfte], with the passive participle as its anchor. It accepts some participles supplied as VBD, but cannot reliably distinguish adjectives from passives or prevent matches across clause boundaries. Its HAS/IS heuristic can mistake *she's left* for a passive. Each of these is a detection limitation.
