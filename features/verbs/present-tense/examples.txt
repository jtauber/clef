# Cases where the tools' rules differ.
She [does] know the answer.
    Emphatic *does* is a finite present form. MAT retags DO before a verb as an emphatic, so its rule misses it.
I [insist] that he {be} told.
    A subjunctive. Stanza's UD features mark it Tense=Pres, so the ud-feats rule counts it.
She [has] to leave.
    Finite present HAVE. MFTE replaces it with its necessity-modal tag, so its rule misses it.
She [needs] to leave.
    Finite present NEED. MFTE applies the same necessity-modal correction.

# Reduced DO NOT KNOW.
I [du]nno.
    One present-tense auxiliary. MFTE's correction requires the three tokens *du n no*. The saved Stanza parse keeps *dunno* as one token tagged RB, so the correction does not run and the MFTE rule misses it.
[Du]nno.
    The same reduced auxiliary with an understood subject. The saved Stanza parse keeps *Dunno* as one token tagged UH. MFTE accepts capitalized *Du* when the three-token split is supplied.
I [do]n't know.
    The unreduced construction: *do* is present tense and *know* is a base form.
